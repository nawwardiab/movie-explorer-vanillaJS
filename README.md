# Movie Explorer - Vanilla JS

Welcome to **Movie Explorer**, a sleek and modern movie discovery application built using **Vanilla JavaScript**, **HTML**, and **CSS**. Movie Explorer allows users to search for movies, view trending, upcoming, and top-rated films, mark favorites, and explore detailed information about each movie, such as cast, trailers, and similar recommendations.

## Features
- **Movie Search**: Quickly find any movie by title using a smart, debounced search field.
- **Trending, Upcoming, and Top-Rated Movies**: Browse the latest trends, upcoming releases, and the top-rated movies, all in visually appealing carousels.
- **Favorite Movies**: Mark your favorite movies, which will be stored locally so you can revisit them anytime.
- **Movie Details**: Click on a movie card to see additional details like ratings, cast, trailers, and more.
- **Light/Dark Theme**: Switch between light and dark themes for a comfortable viewing experience, stored locally for a personalized touch.

## Tech Stack
- **JavaScript (Vanilla)**: All interactivity and functionality are built using plain JavaScript.
- **HTML/CSS**: The structure and styling are done using responsive design principles for a smooth user experience.
- **TMDB API**: The Movie Database API provides all the movie information displayed in the app.

## Getting Started
To get started, clone the repository and run the app locally. Make sure you have **Node.js** installed if you plan to use any dependencies.

```bash
# Clone the repository
git clone https://github.com/nawwardiab/movie-explorer-vanillaJS.git

# Navigate into the project directory
cd movie-explorer-vanillaJS

# Open index.html in your browser
```

## Usage
1. **Search Movies**: Use the search bar to find your favorite movies.
2. **Browse Movie Categories**: Check out trending, upcoming, and top-rated movies right on the homepage.
3. **Mark Favorites**: Click on the heart icon to mark a movie as a favorite and keep it in your personal collection.
4. **View Details**: Click on any movie card to open a modal with movie details, including a trailer link and cast information.
5. **Toggle Theme**: Use the "Toggle Theme" button to switch between dark and light mode.
